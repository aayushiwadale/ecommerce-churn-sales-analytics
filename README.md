# 🛒 E-Commerce Churn and Sales Analytics Dashboard

An end-to-end data analytics project examining customer churn, customer segmentation, and sales performance using Oracle SQL and Power BI.

## 📊 Project Overview
- **Data Source**: Online Retail transaction dataset.
- **Data Processing**: Oracle SQL (`01_rfm_customer_summary.sql`) for data cleansing, feature engineering, and RFM (Recency, Frequency, Monetary) scoring.
- **Visualization**: Power BI (`Ecommerce_Churn_Analytics.pbix`) featuring dynamic KPI cards, customer segmentation breakdown, and revenue trends.

## 🔑 Core Metrics & Measures (DAX)
- **RFM Analysis & Segmentation**: Grouped customers into distinct tiers (VIP, Loyal, At-Risk, etc.).
- **90-Day Churn Threshold**: Categorized customers into Active vs. Churned status.
- **Key DAX Measures**: Total Revenue, Total Customers, Churned Customers, and Churn Rate %.
